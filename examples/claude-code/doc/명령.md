# 명령

> 기본 제공 명령과 번들 스킬을 포함하여 Claude Code에서 사용할 수 있는 명령에 대한 전체 참조입니다.

명령은 세션 안에서 Claude Code를 제어합니다. 명령을 사용하면 모델 전환, 권한 관리, 컨텍스트 지우기, 워크플로 실행 등을 빠르게 수행할 수 있습니다.

`/`를 입력하면 사용 가능한 명령을 볼 수 있으며, `/` 뒤에 글자를 입력하면 목록을 필터링할 수 있습니다. [명령 메뉴가 입력 내용과 일치하는 항목을 찾는 방식](#how-the-command-menu-matches-what-you-type)에서는 강조 표시, 오타 처리, 그리고 Claude Code가 전체 이름을 입력하기 전까지 메뉴에서 숨기는 몇 가지 명령에 대해 설명합니다.

명령은 메시지의 시작 부분에 있을 때만 인식됩니다. 명령 이름 뒤에 오는 텍스트는 해당 명령의 인수가 됩니다. [스킬](/docs/ko/skills#pass-arguments-to-skills)은 예외입니다. `/skill-a /skill-b do XYZ`처럼 스킬 호출 뒤에 다른 스킬이 이어지면, 시작 부분에 지정된 스킬을 로드하고 뒤따르는 텍스트를 각 스킬에 인수로 전달합니다. 최대 6개의 스킬을 연결할 수 있습니다.

Claude가 응답하는 중에 명령을 보내면 Claude Code는 해당 명령을 대기열에 추가하고 현재 턴이 끝난 후 실행합니다. `/status`, `/tasks`, `/usage`와 같은 일부 명령은 응답을 중단하지 않고 즉시 실행됩니다. [전체 화면 렌더링](/docs/ko/fullscreen)에서는 `/theme`, `/help`와 같은 대화 상자 명령도 즉시 열립니다. v2.1.234 이전에는 Claude Code가 이러한 대화 상자를 턴이 끝날 때까지 대기열에 보관했습니다.

<h2 id="commands-across-a-typical-workflow">
  일반적인 워크플로 전반의 명령
</h2>

대부분의 명령은 프로젝트 설정부터 변경 사항 배포에 이르기까지 세션의 특정 시점에 유용합니다.

**리포지토리에서의 첫 세션.** `/init`을 실행하여 초기 `CLAUDE.md`를 생성한 다음, `/memory`로 이를 다듬습니다. `/mcp`를 사용하여 프로젝트에 필요한 서버를 설정하고, 원하는 [서브에이전트](/docs/ko/sub-agents)를 만들도록 Claude에게 요청한 뒤, `/permissions`를 실행하여 승인 규칙을 설정합니다.

**작업 중.** `/plan`은 대규모 변경 전에 플랜 모드로 전환합니다. `/model`과 `/effort`는 사용 중인 모델과 모델이 적용하는 추론의 양을 조정합니다. 대화가 길어지면 `/context`가 윈도우를 채우고 있는 내용을 보여 주고, `/compact`가 이를 요약하여 공간을 확보합니다. 대화 기록에 추가되지 않아야 하는 부수적인 질문에는 `/btw`를 사용합니다.

**병렬로 작업 실행.** Claude는 부수적인 작업을 [서브에이전트](/docs/ko/sub-agents)에 위임하며, `/tasks`는 완료된 서브에이전트를 포함하여 현재 세션의 백그라운드 작업을 나열합니다. `/background`는 전체 세션을 분리하여 [백그라운드 에이전트](/docs/ko/agent-view)로 계속 실행되도록 하고 터미널을 비워 줍니다. 코드베이스 전반에 걸친 대규모 변경의 경우, `/batch`가 이를 독립적인 단위로 분해하고 각 단위를 자체 [worktree](/docs/ko/worktrees)에서 실행합니다. 이러한 접근 방식들이 서로 어떻게 연관되는지는 [에이전트 병렬 실행](/docs/ko/agents)을 참조하십시오.

**배포 전.** `/diff`는 변경된 내용을 보여 줍니다. `/code-review`는 현재 diff에서 정확성 버그를 검사하며 `--fix`로 발견 사항을 적용할 수 있습니다. 대신 풀 리퀘스트를 리뷰하려면 `/code-review high 1234`처럼 PR 번호를 전달합니다. `/review`는 별칭입니다. `/code-review ultra`는 클라우드에서 멀티 에이전트 리뷰를 실행합니다. `/security-review`는 diff에서 보안 취약점을 검사합니다.

**세션 간.** `/clear`는 프로젝트 메모리를 유지하면서 새 작업을 새롭게 시작합니다. `/resume`은 이전 대화로 돌아가고, `/branch`는 다른 방향을 시도하기 위해 현재 대화를 분기하며, `/fork`는 이를 새 [백그라운드 세션](/docs/ko/agent-view)으로 복사합니다. `/teleport`는 클라우드 세션을 이 터미널로 가져오고, `/remote-control`을 사용하면 다른 기기에서 이 로컬 세션을 이어서 진행할 수 있습니다.

**문제가 발생한 경우.** `/rewind`는 코드와 대화를 체크포인트로 되돌리거나 대화의 일부를 요약합니다. `/doctor`는 설치 및 구성 문제를 진단하고 해결할 수 있는 설정 점검을 실행하고, `/debug`는 런타임 문제를 진단하며, `/feedback`은 세션 컨텍스트를 첨부하여 버그를 보고합니다.

<h2 id="all-commands">
  모든 명령
</h2>

아래 표에는 Claude Code에 포함된 모든 명령이 나열되어 있습니다. 대부분은 동작이 CLI에 직접 구현된 기본 제공 명령입니다. 다음 두 종류의 항목은 별도로 표시됩니다.

- **[스킬](/docs/ko/skills#bundled-skills)**: 번들 스킬입니다. 사용자가 직접 작성하는 스킬과 같은 방식으로 작동하며, Claude에게 전달되는 프롬프트입니다.
    - `/verify`는 사용자가 호출할 때만 실행됩니다. v2.1.215 이전에는 Claude가 스스로 `/verify`를 실행할 수도 있었습니다.
- **[워크플로](/docs/ko/workflows#bundled-workflows)**: 작업을 여러 서브에이전트에 분산하여 백그라운드에서 실행하는 번들 [동적 워크플로](/docs/ko/workflows)입니다.
    - `/deep-research`는 사용자가 호출할 때만 실행됩니다. v2.1.218 이전에는 Claude가 스스로 시작할 수도 있었습니다.

직접 명령을 추가하려면 [스킬](/docs/ko/skills)을 참조하세요.

아래 표에서 `<arg>`는 필수 인수를, `[arg]`는 선택적 인수를 나타냅니다.

<Note>
  모든 사용자에게 모든 명령이 표시되는 것은 아닙니다. 사용 가능 여부는 플랫폼, 플랜, 환경에 따라 달라집니다. 예를 들어 `/desktop`은 Claude 구독으로 로그인한 경우 macOS와 x64 Windows에서만 표시되며, `/upgrade`는 Enterprise 플랜에서는 표시되지 않습니다.
</Note>

  명령 메뉴가 입력 내용과 일치하는 방식
</h2>

Claude Code는 입력하는 동안 `/` 메뉴를 필터링합니다. 아래 각 항목은 필터링 중에 확인할 수 있는 사항을 하나씩 다룹니다.

- **강조 표시**: Claude Code는 `/` 뒤의 문자가 명령의 이름이나 별칭과 일치할 때만 최상위 제안을 강조 표시합니다. 이때 이름의 시작 부분이나 이름 안의 단어부터 일치해야 하며, `:`, `_`, `-` 구분자는 무시됩니다. `/adddir`을 입력하면 `/add-dir`이 강조 표시되고, `/new`를 입력하면 별칭을 통해 `/clear`가 강조 표시됩니다. `Enter`를 누르면 강조 표시된 제안이 실행됩니다. 이 강조 표시 규칙은 Claude Code v2.1.236 이상이 필요합니다.
- **오타 입력 후**: Claude Code는 아무것도 강조 표시하지 않습니다. 유사한 항목은 목록에 그대로 남아 있으며 `Tab` 또는 화살표 키로 선택할 수 있지만, `Enter`를 누르면 입력한 텍스트가 그대로 제출되고 [Unknown command](/docs/ko/errors#unknown-command)가 보고됩니다.
- **사용할 수 없는 명령**: Claude Code는 해당 명령을 메뉴에서 제외합니다. 일치하는 항목이 없으면 Claude Code는 `No commands match "/name"`을 표시합니다. 사용할 수 없는 명령 대부분은 제출 시 [Unknown command](/docs/ko/errors#unknown-command)를 반환하지만, [Console API 키에서의 `/schedule`](/docs/ko/routines#schedule-returns-unknown-command)처럼 일부 명령은 대신 자체 사용 가능 여부 메시지로 응답합니다. 또한 일부 명령은 조직의 정책에 의해 비활성화된 경우 자체 메시지로 응답합니다.
- **숨겨진 명령**: Claude Code는 `/heapdump`와 같이 사용 가능한 일부 명령을 의도적으로 메뉴에 표시하지 않습니다. 이름의 일부만 입력해서는 숨겨진 명령이 메뉴에 나타나지 않습니다. 부분 입력이 표시되는 항목과 일치하지 않으면 Claude Code는 동일한 일치 항목 없음 메시지를 표시합니다. Claude Code는 전체 이름을 입력한 경우에만 해당 명령을 목록에 표시하며, 전체 이름을 제출하면 명령이 실행됩니다.
